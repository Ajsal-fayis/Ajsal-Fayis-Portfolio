# Ajsal Fayis M – Software Tester Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Update project links
Edit `projects.js`.

## Update resume
Replace:

`assets/resume/Ajsal_Fayis_Resume.pdf`

Keep the same filename and push the new file to GitHub. The View and Download Resume buttons will continue to work.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload this repository to GitHub and enable GitHub Pages from the repository Settings.
